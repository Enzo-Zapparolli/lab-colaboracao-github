# Laboratório de colaboração com Git e GitHub

**Exercício de aprendizado.** Repositório derivado de um projeto de colaboração, preservando a relação de fork exibida pelo GitHub.

[Portfólio](https://github.com/Enzo-Zapparolli) · [Exemplo Python](APP.py)

## Conteúdo

O arquivo `APP.py` contém um programa simples que imprime `Hello World`. O foco deste repositório é a prática do fluxo de colaboração e versionamento, e não uma aplicação completa.

## Executar

```bash
python APP.py
```

## Conceitos praticados

Git, repositórios remotos, commits e colaboração no GitHub. O histórico original e a atribuição ao repositório de origem foram mantidos.
